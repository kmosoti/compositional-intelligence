# ADR 0001: Evidence-first research

**Status:** Adopted as a process decision. **Date:** 2026-10-18.

## Context
The goal is to investigate compositional intelligent systems, not prematurely ship a product or defend an attractive architecture.

## Decision
Register falsifiable hypotheses; compare independent baselines; separate implementation correctness from scientific merit; retain negative findings. No releases are scheduled.

## Consequences
Research scaffolding and simple reference code come before expensive architectures or extensive abstractions. Any model family remains replaceable.

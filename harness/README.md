# Harness contracts

This repository currently implements instructions, templates, and an offline consistency checker. The autonomous executor, policy sandbox, independent evaluator, integration controller, and GitHub Project writer remain unimplemented. Never mistake a template, checker, or agent role description for an enforced security boundary.

Store scoped task contracts, verification receipts and failure evidence here as the project develops. The controller and evaluator must own acceptance, not the coding agent.

Start with the [coordination contract](../docs/coordination.md) and [record/checker guide](coordination/README.md). Synthetic examples include completed negative research and remain separate from operational records.

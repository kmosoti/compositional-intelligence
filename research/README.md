# Hypothesis registry

Each HYP file names a falsifiable prediction, baseline, evaluation plan and conditions for rejection. A hypothesis ID is not a milestone, release or assigned implementation mandate. Negative results must be retained.

The [research program](../docs/research-program.md) sets the questions. Current implementations and the theories motivating them remain revisable. The [Krakauer review](../docs/research/krakauer-intelligence.md), [harness source review](../docs/research/agent-harness-review.md), and [HELIX assessment](../docs/research/helix-context-review.md) provide different kinds of evidence, not validated results for this project.

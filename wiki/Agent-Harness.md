# Agent harness

Vendor-independent [AGENTS.md](https://github.com/kmosoti/compositional-intelligence/blob/main/AGENTS.md), scoped contracts, focused skills and independent evaluation. Worker and evaluator authority must be separate.

Only scaffold instructions currently exist; there is no trusted execution controller or production sandbox.

See [agent harness design](https://github.com/kmosoti/compositional-intelligence/blob/main/docs/agent-harness.md).

The dated [[Harness-Source-Review]] covers DeepSeek Harness, Pi, and Codex as implementation evidence. It supplies candidate mechanisms for experiments; it does not adopt those architectures or establish cognitive capability.

# Harness source review

The [canonical DeepSeek Harness, Pi, and Codex review](https://github.com/kmosoti/compositional-intelligence/blob/main/docs/research/agent-harness-review.md) preserves the source snapshots inspected on 19 October 2026, the code-reading route, and limitations of each mechanism.

Topics include runtime composition, model request construction, tool execution, concurrency, compaction, permission boundaries, durable state, and recovery. Production paths and representative test bodies were inspected; full test suites and model benchmarks were not executed for that review.

Source code establishes behavior of the inspected implementation. The [[Research-Program]] decides what to test and may replace any candidate architecture. Engineering reliability and scientific evidence of cognition remain separate claims.
